# Sprint 2 - Note Management & Enhancement

**Sprint Goal:** Enable full CRUD operations on notes and add tagging functionality.

**Sprint Duration:** 2 weeks  
**Story Points Committed:** 8

---

## User Stories

### Story 5 – Update Note

**As a** logged-in user  
**I want to** edit a note  
**So that** I can correct or improve it.

**Acceptance Criteria:**
- [ ] Authentication required
- [ ] Must own note
- [ ] Updated data saved

**Priority:** Medium  
**Estimate:** 3 SP

---

### Story 6 – Delete Note

**As a** logged-in user  
**I want to** remove a note  
**So that** I can discard it.

**Acceptance Criteria:**
- [ ] Authentication required
- [ ] Must own note
- [ ] Deletion confirmed

**Priority:** Medium  
**Estimate:** 2 SP

---

### Story 7 – Tag Notes

**As a** user  
**I want to** categorize notes  
**So that** I can find them easily.

**Acceptance Criteria:**
- [ ] Tags can be added
- [ ] Tags appear when fetching notes

**Priority:** Low  
**Estimate:** 3 SP

---

## Definition of Done

A story is considered complete when:

- [ ] Functionality implemented
- [ ] Code builds successfully
- [ ] Unit and integration tests written and passing
- [ ] Code merged to main branch
- [ ] Application is runnable/deployed
- [ ] API endpoints documented
